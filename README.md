# 📐 Matemáticas desde Cero

## 📚 Descripción

Serie de archivos educativos en español diseñada para aprender matemáticas desde lo más básico, sin dar ningún conocimiento por sabido.

El contenido está organizado en módulos independientes, cada uno en su propio archivo `.md` (Markdown), lo que permite descargar los materiales, estudiarlos y consultarlos sin necesidad de conexión a Internet.

## 📖 Archivos disponibles

Actualmente, se encuentra disponible el siguiente módulo:

- **01. Aritmética básica:** introducción a los números, las cuatro operaciones fundamentales, números negativos, orden de las operaciones, potencias y raíces.

## 🗂️ Plan completo del curso

El curso contempla un total de **20 archivos**, organizados para avanzar progresivamente desde los fundamentos matemáticos hasta temas más avanzados.

Entre los contenidos se encuentran:

- Aritmética básica.
- Divisibilidad y números primos.
- Fracciones y porcentajes.
- Razones y proporciones.
- Lógica y razonamiento matemático.
- Álgebra.
- Ecuaciones y sistemas de ecuaciones.
- Funciones.
- Geometría.
- Trigonometría.
- Probabilidad y estadística.
- Matrices.

- Matemática financiera.
- Y otros contenidos fundamentales.

## 📝 Metodología de aprendizaje

Cada módulo está diseñado para facilitar la comprensión de los conceptos mediante explicaciones detalladas y práctica constante.

El contenido incluye:

- **Explicaciones:** cada concepto se desarrolla de diferentes maneras para facilitar su comprensión.
- **Ejemplos resueltos:** procedimientos explicados paso a paso.
- **Problemas prácticos:** numerosos ejercicios de varias partes, similares a los de un libro de texto.
- **Soluciones completas:** resolución detallada de los problemas para comprobar los resultados y comprender los procedimientos.
- **Plan de estudio:** orientación para organizar el aprendizaje y avanzar de manera progresiva.

El objetivo es comprender las matemáticas desde sus fundamentos, desarrollar el razonamiento lógico y aprender a resolver problemas de forma autónoma.

## 🎯 Objetivo del curso

Construir una base matemática sólida, comenzando desde cero y avanzando progresivamente hacia conocimientos más complejos.

Al finalizar el recorrido, tendrás conocimientos de diferentes ramas de las matemáticas y mejores herramientas para afrontar problemas académicos y situaciones de la vida cotidiana.

## 💡 Recomendaciones

- Estudia los módulos en orden.
- No avances hasta comprender los conceptos fundamentales.
- Resuelve los ejemplos por tu cuenta antes de consultar las soluciones.
- Dedica tiempo a los problemas de varias partes.
- Practica constantemente y revisa los temas anteriores.

**Las matemáticas no se aprenden memorizando fórmulas, sino comprendiendo cómo y por qué funcionan.**
